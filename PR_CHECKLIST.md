## 🚀 Comandos Rápidos - Verificación Completa

Ejecuta estos comandos en orden para una verificación rápida:

```bash
# 1. Instalar dependencias
pnpm install

# 2. Formatear código
pnpm run format

# 3. Verificar linting
pnpm run lint

# 4. Compilar proyecto
pnpm run build

# 5. Ejecutar en desarrollo
pnpm run dev
```

## ⚠️ Recordatorios Importantes

- 🚫 **NUNCA** hacer commit sin verificar el linting
- 🚫 **NUNCA** enviar un PR con errores de compilación
- 🚫 **NUNCA** enviar un PR sin probar localmente
- ✅ **SIEMPRE** usar Prettier para formatear el código
- ✅ **SIEMPRE** revisar los cambios antes de hacer commit
- ✅ **SIEMPRE** probar la aplicación después de tus cambios
